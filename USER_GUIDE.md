## Getting Started

### Logging In

1. Open your web browser (Chrome, Safari, Firefox, or Edge)
2. Go to your Havdis Ctrl website address
3. Enter your email address (example: andreas@havdis.no)
4. Enter your password
5. Click the **Login** button

**Note:** Your login credentials are provided by your team administrator.

---

## Dashboard Overview

The Dashboard is the first page you see after logging in. It gives you a quick overview of everything happening in your team.

### What You'll See:

#### Welcome Message
At the top, you'll see a personalized greeting with your name.

#### Statistics Cards
Four boxes showing important numbers:
- **Total Tasks**: All tasks in the system
- **In Progress**: Tasks currently being worked on
- **Completed**: Tasks that are finished
- **Active Milestones**: Current project phases or sprints

#### Quick Actions
Three buttons to help you get started quickly:
- **Create New Task**: Click to add a new task
- **Create Milestone**: Click to start a new project phase
- **View Kanban Board**: Click to see all tasks organized by status

#### Team Overview
See all your team members with:
- Their profile picture and name
- How many tasks they have
- How many tasks they've completed (green bar)
- How many tasks they're currently working on (blue number)
- What task they're currently working on

#### Recent Activity
Shows what your team has been doing recently:
- Who did what
- Which task they worked on
- When it happened (e.g., "2 hours ago")

## Managing Tasks with the Kanban Board

The Kanban Board is where you manage all your tasks visually. Think of it as a digital board with sticky notes.

### Getting to the Kanban Board

Click **Kanban Board** in the left sidebar (the menu on the left side of the screen).

### Understanding the Columns

Tasks are organized in 4 columns from left to right:

1. **To Do** (Gray): Tasks that haven't been started yet
2. **In Progress** (Blue): Tasks currently being worked on
3. **In Review** (Yellow): Tasks waiting to be checked
4. **Done** (Green): Completed tasks

### Moving Tasks Between Columns

To change a task's status:
1. Click and hold on a task card
2. Drag it to a different column
3. Release your mouse or finger
4. The task automatically saves in its new position

**Tip:** This is called "drag and drop" - it's like moving a piece of paper from one pile to another!

### Filtering Tasks

At the top of the Kanban Board, you'll see filter options:

#### Search Box
- Type any word to find tasks
- Searches in task titles and descriptions

#### Filter Dropdowns
- **All Milestones**: Show tasks from a specific project phase
- **All Labels**: Show only tasks with a specific label (like "Bug" or "Feature")
- **All Assignees**: Show only tasks assigned to a specific person

#### Clear Filters
Click the **X** button to remove all filters and see everything again.

### Scrolling Through Tasks

If a column has many tasks, you can scroll up and down within that column to see all tasks.

## Creating and Editing Tasks

### Creating a New Task

**Method 1: From the Dashboard**
1. Click the **Create New Task** button in Quick Actions

**Method 2: From the Kanban Board**
1. Go to the Kanban Board
2. Click the **+ New Task** button at the top right
3. OR click the small **+** icon at the top of any column

### Filling Out Task Details

A form will appear with the following fields:

#### Task Title (Required)
- Give your task a short, clear name
- Example: "Fix login button" or "Create monthly report"

#### Description (Optional)
- Add more details about what needs to be done
- Explain the task so anyone can understand it

#### Status
Choose where the task should start:
- To Do
- In Progress
- In Review
- Done

#### Priority
How urgent is this task?
- **Low**: Can wait (Gray)
- **Medium**: Normal priority (Blue)
- **High**: Important (Orange)
- **Urgent**: Do this first! (Red)

#### Assignees
- Click the dropdown to assign the task to team members
- You can assign a task to multiple people
- Click on names to select them

#### Milestone (Optional)
- Choose which project phase this task belongs to
- Example: "Sprint 1" or "Q1 2024"

#### Labels (Optional)
- Add tags to categorize your task
- Example: "Bug", "Feature", "Design"
- You can add multiple labels

#### Due Date (Optional)
- Click the calendar icon
- Select when the task should be completed
- The date will be highlighted in red if it's overdue

### Saving Your Task

Click the **Create Task** button at the bottom of the form.

### Editing an Existing Task

1. Click on any task card in the Kanban Board
2. The task details will open
3. Change any information you want
4. Click **Update Task** to save your changes

### Deleting a Task

1. Find the task you want to delete
2. Click the small **trash can icon** in the top right corner of the task card
3. Confirm that you want to delete it
4. The task will be permanently removed

**Warning:** Deleted tasks cannot be recovered, so be careful!

## Using Milestones

Milestones help you organize tasks into project phases or sprints (like chapters in a book).

### Viewing Milestones

Click **Milestones** in the left sidebar.

### Creating a Milestone

1. Click the **+ New Milestone** button
2. Fill in the details:
   - **Name**: Give it a clear name (e.g., "Website Launch" or "Sprint 1")
   - **Description**: Explain what this phase is about
   - **Start Date**: When does this phase begin?
   - **End Date**: When should it be completed?
   - **Status**: Choose from Planned, Active, Completed, or Archived
3. Click **Create Milestone**

### Viewing Tasks in a Milestone

1. Click on any milestone card
2. You'll see all tasks assigned to that milestone
3. You'll also see:
   - How many tasks are in each status
   - Overall progress percentage
   - Who is working on what

### Editing a Milestone

1. Click on the milestone you want to edit
2. Click the **Edit** button
3. Make your changes
4. Click **Update Milestone**

## Working with Your Team

### Viewing Team Members

Click **Team** in the left sidebar to see everyone.

### What You Can See About Each Team Member

Each team member card shows:
- Profile picture
- Name and email
- Current availability status:
  - **Green dot**: Available
  - **Red dot**: Busy
  - **Yellow dot**: Away
  - **Gray dot**: Offline
- Bio (what they do)
- Skills (what they're good at)
- Total number of tasks
- Current task they're working on

### Understanding Workload

The cards help you see:
- Who is busy (lots of tasks)
- Who has capacity (fewer tasks)
- What everyone is working on right now

This helps you assign new tasks fairly!

## Using Labels

Labels are like colored stickers you can put on tasks to categorize them.

### Viewing Labels

Click **Labels** in the left sidebar.

### Creating a New Label

1. Click **+ New Label**
2. Enter a name (e.g., "Bug", "Feature", "Design", "Urgent")
3. Choose a color
4. Click **Create**

### Using Labels on Tasks

When creating or editing a task:
1. Click in the **Labels** field
2. Select one or more labels
3. The labels will appear as colored tags on the task card

### Editing or Deleting Labels

1. Go to the Labels page
2. Click on the label you want to change
3. Edit the name or color, or click **Delete**

## Calendar View

The Calendar shows all your tasks with due dates in a traditional calendar format.

### Opening the Calendar

Click **Calendar** in the left sidebar.

### Navigating the Calendar

- Use the **arrow buttons** at the top to move between months
- Click **Today** to jump back to the current date

### Viewing Tasks on the Calendar

- Tasks appear on their due dates as colored blocks
- The color shows the task's priority
- Click on any task to see its details

### Creating Tasks from the Calendar

1. Click on any date
2. A new task form will open with that date pre-selected
3. Fill in the task details
4. Click **Create Task**

## Profile Settings

### Accessing Your Profile

Click the **gear/settings icon** in the top right corner of the screen.

### What You Can Update

#### Profile Picture
- Click **Change Avatar**
- Upload a photo from your computer
- Recommended size: Square image, at least 200x200 pixels

#### Personal Information
- **Name**: Your full name
- **Email**: Your email address (used for login)
- **Bio**: Tell your team about yourself
- **Skills**: What you're good at (separate with commas)

#### Status
Choose your current availability:
- **Available**: Ready to work
- **Busy**: Working on something, don't disturb
- **Away**: Not at desk, will return later
- **Offline**: Not working right now

#### Password
To change your password:
1. Enter your current password
2. Enter your new password
3. Confirm your new password
4. Click **Update Password**

**Important:** Choose a strong password with letters, numbers, and symbols!

### Saving Changes

Click **Update Profile** at the bottom to save all your changes.

## Notifications

Notifications keep you informed about important updates.

### Viewing Notifications

Click the **bell icon** in the top right corner.

### Types of Notifications

You'll receive notifications when:
- Someone assigns you a task
- Someone mentions you in a comment
- A task you're assigned to is updated
- A task deadline is approaching
- Someone comments on your task

### Managing Notifications

- **Unread notifications** appear with a blue dot
- Click on a notification to see more details
- Click **Mark all as read** to clear all notifications

## Tips for Success

### Daily Routine

1. **Start your day**: Check the Dashboard to see what's happening
2. **Update your tasks**: Move tasks on the Kanban Board as you work
3. **Communicate**: Add comments to tasks when you have questions
4. **Update your status**: Let your team know if you're available or busy
5. **Check notifications**: Stay informed about what your team is doing

### Best Practices

- **Keep task titles short and clear**: Others should understand what needs to be done
- **Update task status regularly**: Move tasks as soon as you start or finish them
- **Set realistic due dates**: Give yourself enough time
- **Use labels consistently**: Agree with your team on what each label means
- **Assign tasks fairly**: Check the Team page to see who has capacity
- **Add descriptions**: Help others understand complex tasks
- **Check in daily**: Spend 5 minutes each day updating your work

### Getting Help

If you're stuck or have questions:
1. Ask your team administrator
2. Try the feature again slowly, following each step
3. Check if you have the right permissions (some features may require admin access)

## Troubleshooting Common Issues

### I Can't Log In
- Check that your email and password are correct (passwords are case-sensitive)
- Make sure Caps Lock is off
- Try refreshing the page
- Contact your administrator for password reset

### Tasks Won't Move on the Kanban Board
- Make sure you're clicking and holding the task
- Try using a mouse instead of a trackpad
- Refresh the page and try again

### I Can't See All My Tasks
- Check if you have filters applied (look for the X button to clear filters)
- Make sure you're looking in the right column
- Try using the search box to find the task

### Changes Aren't Saving
- Check your internet connection
- Look for error messages in red
- Try refreshing the page (your changes might have saved)
- If the problem continues, contact your administrator

### The Page Looks Broken or Strange
- Try refreshing the page (press F5 or Ctrl/Cmd + R)
- Clear your browser cache
- Try a different web browser
- Make sure you're using a modern browser (Chrome, Firefox, Safari, or Edge)

## Glossary of Terms

- **Dashboard**: The main page showing an overview of everything
- **Kanban Board**: A visual board showing tasks organized by status
- **Task**: A piece of work that needs to be done
- **Milestone**: A project phase or sprint containing multiple tasks
- **Label**: A colored tag to categorize tasks
- **Assignee**: The person responsible for completing a task
- **Status**: Where a task is in the workflow (To Do, In Progress, etc.)
- **Priority**: How urgent or important a task is
- **Due Date**: The deadline for completing a task
- **Filter**: A way to show only specific tasks
- **Drag and Drop**: Clicking, holding, and moving something with your mouse
